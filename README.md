# Modelado y Simulación de Sistemas · Guía no oficial UPCT

Guía de estudio de la asignatura (Grado en Ingeniería Electrónica Industrial y Automática, UPCT): con la misma estructura que la guía de Control por computador: portada, una página por unidad, prácticas, problemas, examen, autoevaluación, formulario, glosario, plan de estudio, buscador y guía completa en una sola página.

Web: https://helionacon-ui.github.io/Modelado-y-Simulaci-n-de-Sistemas/

Parte del índice de guías: https://helionacon-ui.github.io/GIEIA-UPCT/

La carpeta `fuente/` contiene los fragmentos y el script (`python3 build_site.py`) con los que se genera la web. Proyecto personal de estudio; no es una página oficial de la UPCT.
